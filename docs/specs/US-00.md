# US-00 — Car insurance landing page

**Working spec** · [Country ADR](../adr/001-country-content.md) · [Wizard scope](../../SCOPE.md)

Owner request: “Be the lead code and start working create the first landing page for our insurance page for cars read flow.md”

As a prospective policyholder, I want to visit the Sura car insurance page for my country and see where to start a quote.

| ID | Acceptance criterion |
| --- | --- |
| AC1 | One Angular build serves `/cl` in `es-CL` and `/co` in `es-CO`. Show the active country and let customers switch to the other country. Direct navigation and reload preserve the route's market. |
| AC2 | Show only published landing content returned by Strapi for the active market. Missing, invalid, or failed content requests show a Spanish unavailable state. Switching markets clears the previous market's content. |
| AC3 | The quote action preserves the active market. Where quote setup is unavailable, show a Spanish status before collecting any information. The landing page precedes the wizard steps defined in scope. |
| AC4 | Customers can use the landing page at mobile and desktop widths and reach its controls by keyboard. Keep visible focus and offer accessible names for the country links and quote action. |

The owner authorized starting this landing increment. Final spec approval and the approved revision are pending. The proposed age threshold and date rules remain with [US-01](US-01.md).
