# US-00 — Car insurance landing page

**Working spec** · [Country ADR](../adr/001-country-content.md) · [Wizard scope](../../SCOPE.md)

Owner request: “Be the lead code and start working create the first landing page for our insurance page for cars read flow.md”

The owner later directed the team to use neutral branding, remove the mock content API and its fixtures, and run local content through real Strapi.

As a prospective policyholder, I want to visit the car insurance page for my country and see where to start a quote.

| ID | Acceptance criterion |
| --- | --- |
| AC1 | One Angular build serves `/cl` in `es-CL` and `/co` in `es-CO`. Show the active country and let customers switch countries. Direct navigation and reload preserve the route's market. |
| AC2 | Show only published landing content from Strapi 5 for the active market. An unpublished edit leaves the last published content visible. Publishing updates the page after reload, without rebuilding Angular. Switching clears the previous market's content. A missing, invalid, or failed response shows a Spanish unavailable state. |
| AC3 | The quote action preserves the active market. Where quote setup is unavailable, show a Spanish status before collecting any information. The landing page precedes the wizard steps defined in scope. |
| AC4 | Customers can use the page at mobile and desktop widths and reach its controls by keyboard. Keep visible focus and accessible names for the country links and quote action. |
| AC5 | Landing, market selection, and quote entry use neutral car insurance wording and imagery, including page titles and unavailable states. The owner selected the existing mountain-road hero for `/cl` and coffee plants, native nature, and a hummingbird for `/co`. Both hero images have descriptive Spanish alt text. |
| AC6 | Local startup runs real Strapi 5 and seeds one published landing entry per market in a fresh data store. Editors can change and publish entries in Strapi. Restarting preserves stored draft and published changes. Remove the mock content API and its fixtures. |

The owner authorized the landing increment and directed the branding and content corrections. Final spec approval and the approved revision are pending. The proposed age threshold and date rules remain with [US-01](US-01.md).
