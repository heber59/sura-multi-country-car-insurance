# US-03 — Summary and simulated payment

**Draft** · Source: assessment, pages 8–9 · [Country ADR](../adr/001-country-content.md)

As a person who selected a plan, I want to review my quote and complete simulated payment.

## Acceptance criteria

| ID | Acceptance criterion |
| --- | --- |
| AC1 | Show policyholder and vehicle details, selected plan, and final price. Partially mask the document number. Let the user go back to edit details or change plans. |
| AC2 | Show published Strapi terms for the selected country. Enable payment only after the user accepts the applicable terms. Keep payment disabled if terms are unavailable. |
| AC3 | Lock payment while processing and prevent a second submission after success. On success show a confirmation with a simulated quote number. |
| AC4 | On simulated rejection, show a clear error and allow retry with the entered details and selected plan preserved. |

See the [AC2 evidence example](../story-records.md#worked-example-for-us-03-ac2) for the terms decision and the checks at each stage.
