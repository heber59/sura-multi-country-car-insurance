# US-01 — Policyholder and vehicle form

**Draft** · Source: assessment, pages 5–6 · [Country ADR](../adr/001-country-content.md)

As a prospective policyholder, I want to enter my details and vehicle information to receive relevant insurance options.

| ID | Acceptance criterion |
| --- | --- |
| AC1 | Render only published form configuration for the route country, in Strapi order. Each field has a label, type, required flag, validations, help text, and error message. Support text, number, select, date, and checkbox. Load select options from Strapi. |
| AC2 | Show configured errors beside invalid fields and prevent progress. Validate legal age and accept vehicle years from the current year minus 20 through next year, inclusive. Confirm the age threshold and date handling during spec approval. |
| AC3 | A newly published field appears after reload without a frontend change. |
| AC4 | Back from plans restores the entered values for the same market. |
