# US-02 — Plan list

**Draft** · Source: assessment, pages 6–7 · [Country ADR](../adr/001-country-content.md)

As a person getting a quote, I want to compare eligible plans and choose one.

| ID | Acceptance criterion |
| --- | --- |
| AC1 | After valid form completion, show only active, published plans from the selected market, in Strapi order. Show each plan's name, short description, price, coverages, and benefits. |
| AC2 | Format prices as COP for Colombia and CLP for Chile. Use the configured base price as the final price. |
| AC3 | Visually distinguish any plan marked recommended in Strapi. |
| AC4 | Allow exactly one current selection. Enable progression to summary once a plan is selected. |
| AC5 | If the eligible list is empty, explain that no plans are available and prevent progression. |
